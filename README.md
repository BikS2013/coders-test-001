# Rating Dashboard

An interactive dashboard for visualizing chatbot ratings, built with React, TypeScript, and Recharts.

## Features

- Filter ratings by users, time periods, and rating categories
- Interactive charts for visualizing rating distribution
- Collapsible sidebar for maximum screen real estate
- Custom date range selection with calendar picker
- Responsive design for all screen sizes

## Tech Stack

- React 19
- TypeScript
- Tailwind CSS
- Recharts (for data visualization)
- Lucide React (for icons)
- Vite (for build and development)

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Project Structure

- `src/components/Dashboard.tsx` - Main dashboard component
- `src/App.tsx` - Application entry point
- `public/` - Static assets
